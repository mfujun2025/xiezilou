## 网站定位

一个单页落地页，核心就一件事：**让客户看到园区、知道优惠、留个电话/微信**。

## 技术实现（极简版）

| 方案 | 说明 |
|------|------|
| **推荐** | GitHub Pages / Cloudflare Pages 静态站 |
| **框架** | 原生 HTML + Tailwind CSS（CDN 引入，无需构建） |
| **部署** | 一个 index.html，推上去就行 |
| **统计** | Cloudflare Web Analytics（自动埋点） |
| **备案** | `.cn` 域名需备案，用国内主机或走 Cloudflare Tunnel 到国内服务器 |
| **表单** | 联系表单用腾讯文档收集 / 或使用 Formspree（免费） |

### 项目文件结构
```
index.html        ← 全部代码在这个文件
├── <head>        ← Tailwind CDN + SEO meta
├── <body>        ← 所有<section>
└── <script>      ← 可选：平滑滚动 + 移动端菜单
```

预估开发时间：**1-2 天**（一人可完成）
